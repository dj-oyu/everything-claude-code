# generate-driverコマンド

このコマンドは、`esp_idf_specialist`エージェントと関連するスキル（`spi_driver`、`i2c_device`など）を呼び出し、新しいハードウェアドライバのボイラープレートコードを生成します。ユーザーがデバイスの種類、インターフェース、主要な機能を提供すると、エージェントはESP-IDFの標準的なコーディングプラクティスに沿ったドライバのひな形を作成します。

## このコマンドの機能

1.  **対話型での要件収集**: ユーザーから、ドライバを開発するデバイスのインターフェース（SPI、I2Cなど）、主要な機能、使用するGPIOピン、通信プロトコルなどの情報を収集します。
2.  **スキルベースのコード生成**: 収集した情報と、`spi_driver`や`i2c_device`といったスキルを活用して、ドライバの初期化、データ送受信、エラーハンドリングなどの基本構造を含むC言語のコードを生成します。
3.  **ESP-IDFのベストプラクティスに準拠**: 生成されるコードは、`esp_err_t`を用いたエラーハンドリング、`ESP_LOGx`を用いたロギング、FreeRTOSタスクとの連携など、ESP-IDFの推奨プラクティスに準拠します。
4.  **カスタマイズ可能なひな形**: 生成されたコードは、ユーザーが容易にデバイス固有のロジックを追加できるように設計されています。

## 使用する場面

*   新しいセンサー、アクチュエータ、またはその他のペリフェラルデバイスのドライバ開発を開始するとき。
*   ESP-IDFプロジェクトに既存のドライバを統合する際の出発点として。
*   標準的な通信プロトコル（SPI、I2C）の基本的なドライバ実装が必要なとき。

## 仕組み

`generate-driver`コマンドが起動されると、以下のプロセスが進行します。

1.  エージェントは、どの種類のドライバ（例: SPI、I2C）が必要か、そのデバイスの主要な機能、接続ピンなどの詳細をユーザーに質問します。
2.  ユーザーからの回答に基づき、関連するスキルをアクティブ化し、ドライバの骨格となるコードを生成します。
3.  生成されたコードは、新しいコンポーネントとしてプロジェクトに統合できる形式で提供されます。

## 使用例

### I2Cセンサーのドライバを生成する

```
/generate-driver "I2Cインターフェースの温度センサーMCP9808のドライバを生成してください。アドレスは0x18、レジスタ読み書きで温度を取得します。"
```
エージェントは、MCP9808と通信するためのI2Cドライバのひな形を生成し、初期化、レジスタの読み書き関数のスケルトンを提供します。

### SPIディスプレイのドライバを生成する

```
/generate-driver "SPIインターフェースのディスプレイドライバを生成してください。高速なデータ転送が必要で、DMAを使用したいです。ピン配置はSCLK: 12, MOSI: 11, CS: 10, DC: 9, RST: 8です。"
```
エージェントは、SPIディスプレイドライバのひな形を生成し、SPIバスの初期化、DMA対応バッファの使用、一般的なディスプレイコマンド送信関数のスケルトンを提供します。
