# debug-hardwareコマンド

このコマンドは、`hardware-debugger`エージェントを呼び出し、M5Stack Tab5のようなESP32ベースのデバイスで発生する可能性のあるハードウェア関連の問題（GPIOの誤動作、I2C/SPI通信エラー、ディスプレイ表示の問題、電源供給異常など）を診断・解決するためのインタラクティブなガイドを提供します。

## このコマンドの機能

1.  **問題の症状分析**: ユーザーから提供された情報に基づき、ハードウェア問題の可能性を評価します。
2.  **設定の検証**: GPIOピン配置、I2C/SPIバスの初期化、ディスプレイ設定など、ソフトウェア側の設定が正しいかを確認します。
3.  **診断ツールの提案**: 問題の種類に応じて、`bsp_i2c_scan()`、ロジックアナライザ、オシロスコープ、マルチメータなどの利用を提案します。
4.  **トラブルシューティングフローの誘導**: 体系的なデバッグプロセス（ログ確認、基本機能検証、ピン配置確認、電源確認など）に従って、問題解決を支援します。
5.  **M5Stack Tab5特有のガイダンス**: M5Stack Tab5の回路図やBSPの関数 (`m5stack_tab5.c`など) に基づいた具体的なアドバイスを提供します。

## 使用する場面

*   デバイスの特定のハードウェアコンポーネントが応答しない、または期待通りに動作しない場合。
*   センサーからのデータが不正であるか、全く読み取れない場合。
*   ディスプレイに何も表示されない、または表示がおかしい場合（ティアリング、フリーズなど）。
*   デバイスが予期せぬ再起動を繰り返すなど、電源関連の問題が疑われる場合。
*   ハードウェア関連のエラーログ (`ESP_LOGE`など) が出力されている場合。

## 仕組み

`hardware-debugger`エージェントは、ユーザーとの対話を通じて問題の詳細を収集し、その情報に基づいて診断ステップと解決策を提案します。必要に応じて、特定のコードの確認や、物理的なデバッグツールの使用を促します。

## 使用例

### ハードウェアデバッグを開始する

```
/debug-hardware
```
エージェントは問題の症状について質問し、診断を開始します。

### 特定のコンポーネントに焦点を当てる場合

```
/debug-hardware "I2Cバスでセンサーが検出されません"
```
```
/debug-hardware "ディスプレイのバックライトが点灯しません"
```

## 関連エージェント

このコマンドは、`m5stack_esp_idf_docs/agents/hardware_debugger.md`に定義されている`hardware-debugger`エージェントを呼び出します。
