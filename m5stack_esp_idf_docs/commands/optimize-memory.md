# optimize-memoryコマンド

このコマンドは、`memory-optimizer`エージェントを呼び出し、ESP32/ESP32-P4ベースのプロジェクトにおけるメモリ使用量を分析し、最適化するためのガイドと提案を提供します。メモリリーク、スタックオーバーフロー、過度なFlash使用などの問題を解決します。

## このコマンドの機能

1.  **メモリ使用状況のレポート**: `idf.py size`の結果を解析し、RAM（データ、BSS、ヒープ）とFlash（コード、ROデータ）の使用状況を報告します。
2.  **問題の特定**: メモリリークの可能性、スタックオーバーフローのリスク、PSRAMの非効率な使用などを特定します。
3.  **最適化戦略の提案**: コードのリファクタリング、データ構造の変更、コンパイラ最適化フラグの調整など、メモリを節約するための具体的な方法を提案します。
4.  **コード例の提供**: 提案された最適化を実装するためのコード例を提供します。

## 使用する場面

*   `idf.py size`の結果でRAMまたはFlashの使用量が多すぎる場合。
*   アプリケーションの実行中に`heap_caps_malloc`が`NULL`を返す（メモリ不足）場合。
*   タスクがクラッシュし、「Guru Meditation Error: Core X panic'ed (Stack overflow)」などのスタックオーバーフローエラーが発生する場合。
*   PSRAMが有効になっているにもかかわらず、大きなバッファが割り当てられない場合。
*   ファームウェアのバイナリサイズを削減したい場合。

## 仕組み

`memory-optimizer`エージェントは、まず現在のメモリ使用状況に関する情報を収集します。その後、ユーザーの目標や特定された問題に基づいて、最適なメモリ管理戦略や最適化手法を提案します。

## 使用例

### メモリ使用状況の分析を開始する

```
/optimize-memory
```
エージェントは現在のプロジェクトのメモリプロファイルに関する質問を始めます。

### 特定のメモリ問題を分析する

```
/optimize-memory "タスクAでスタックオーバーフローが発生しています"
```
```
/optimize-memory "ヒープメモリが徐々に減少しています"
```
```
/optimize-memory "ファームウェアのサイズが大きすぎます"
```

## 関連エージェント

このコマンドは、`m5stack_esp_idf_docs/agents/memory_optimizer.md`に定義されている`memory-optimizer`エージェントを呼び出します。
