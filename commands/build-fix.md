# ビルドと修正

TypeScriptとビルドのエラーをインクリメンタルに修正する：

1. ビルドを実行: `npm run build` または `pnpm build`

2. エラー出力を解析:
   - ファイルごとにグループ化
   - 重大度でソート

3. 各エラーについて:
   - エラーのコンテキストを表示（前後5行）
   - 問題を説明する
   - 修正を提案する
   - 修正を適用する
   - ビルドを再実行する
   - エラーが解決したことを確認する

4. 以下の場合に停止する:
   - 修正が新しいエラーを導入した場合
   - 3回試行しても同じエラーが続く場合
   - ユーザーが一時停止を要求した場合

5. サマリーを表示:
   - 修正されたエラー
   - 残りのエラー
   - 新たに導入されたエラー

安全のために一度に一つのエラーを修正すること！
